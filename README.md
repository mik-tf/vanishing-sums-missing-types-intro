# Which ways of adding up to zero did a list miss?

Author: Michaël Perreault

An introduction, in plain language, to the research paper *Missing types in the conjectural classification of minimal vanishing sums of roots of unity of weights 17 to 21* (concept DOI [10.5281/zenodo.24562183](https://doi.org/10.5281/zenodo.24562183)). The paper has the proofs. This note has the idea, and it says what the paper does and does not claim.
